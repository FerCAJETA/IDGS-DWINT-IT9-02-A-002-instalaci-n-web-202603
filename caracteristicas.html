Arquitectura y Versionamiento

El código fuente se gestiona mediante Git y se aloja en un repositorio de GitHub, aplicando commits incrementales para documentar cada fase del desarrollo.

Especificaciones de Despliegue

  • Frontend: HTML5 semántico y hojas de estilo CSS3 sin dependencias externas.
  • CI/CD en Azure: Flujo de trabajo automático con GitHub Actions hacia Azure Static Web Apps.
  • Servidor Linux en Oracle Cloud: Instancia Compute VM con puerto 80 habilitado y servidor web Apache/Nginx.
